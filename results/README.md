# Historical Results

This directory contains selected artifacts from the 2023 thesis experiments. They were retained for inspection and storytelling; they were not regenerated or independently reproduced for the 2026 public portfolio edition.

## Inventory

| Path | Contents | Interpretation status |
| --- | --- | --- |
| `fitness/*.png` | Historical convergence plots for the 2012 and 2015 comparisons | Visual evidence only; no seed or run manifest is available |
| `fitness/fitness-history-*.csv` | Data-only transcription of the convergence series formerly embedded in plotting snippets | Historical values, not a new run |
| `figures/network_graphs/` | Cumulative historical-network maps for 2009-2022 | No generating revision or input checksum is attached |
| `figures/network_graphs_optimized/` | Simulated-network maps for selected years | No generating revision or seed is attached; two 2015 variants are retained because their provenance is unresolved |
| `figures/statistics/` | Registry summaries and exported workbooks | Historical data products; not regenerated after code maintenance |
| `network-metrics-2009-2022.xlsx` | Historical component-weighted network metrics | No generating revision, routing cache, or input checksum is attached |

The workbook `figures/statistics/connector-types-by-year-legacy.xlsx` was generated by legacy preprocessing that encoded missing secondary connectors as `0`. The maintained code now preserves those values as missing and filters legacy sentinels, but this workbook has not been rebuilt. Do not use its connector totals as validated statistics.

The topology and optimization artifacts also predate the corrected 100 km OSRM prefilter in `src/utils.py`. Consequently, they must not be presented as newly validated road-network results. The thesis tables, contradictions, and methodological limitations are documented in [`docs/RESEARCH_NOTES.md`](../docs/RESEARCH_NOTES.md); the missing provenance and execution inputs are documented in [`docs/REPRODUCIBILITY.md`](../docs/REPRODUCIBILITY.md).

No artifact in this directory is suitable as a production benchmark or operational siting recommendation.
