# Archived Notebooks

The notebooks in [`archive/`](archive/) are the original, unexecuted narrative interfaces from the 2023 thesis project. Their code cells have no stored execution counts or outputs, and several cells duplicate an earlier form of logic that is now maintained in `src/`.

Use the notebooks to inspect the historical research sequence, not as evidence that the current repository reproduces the thesis from a clean clone. For code review or future maintenance, treat `src/` as the source of truth. For execution requirements and missing artifacts, see [`docs/REPRODUCIBILITY.md`](../docs/REPRODUCIBILITY.md).
